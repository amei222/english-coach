# 🗣️ SpeakUp · 英语精进

目标：**雅思 G 类 5.5 → 新西兰 / 澳洲打工度假**。每天约 25 分钟，手机电脑都能用，进度自动同步。

> 新西兰（中国公民）打工度假签证要求雅思总分 5.5；澳洲 462 签证要求平均 4.5（需先抽签）。两国都接受雅思 G 类，且必须在考点考。政策会变，申请前以两国移民局官网为准。

## 「雅思」页面

- **口语模考**：Part 1 四题 → Part 2 → Part 3 三题，约 12 分钟
- **写作批改**：G 类小作文（书信）和大作文，也可以粘贴自己的题目；四项评分 + 改错 + 6.5 分改写版
- **成绩与计划**：记录《剑桥雅思》听力/阅读答对题数，自动换算分数；结合口语、写作估分算出预估总分；填考试日期后按阶段给建议

题库是按雅思题型原创的练习题，正式备考请配合《剑桥雅思》真题。

## 开始使用

1. 电脑、手机打开 https://amei222.github.io/english-coach/ ，手机上「添加到主屏幕」。
2. **我的 → AI 设置**：填 API Key（推荐 DeepSeek，国内直连、便宜）。
3. **我的 → 语音识别**：推荐开启硅基流动 SenseVoice（免费、对中国口音更友好）。
4. **我的 → 多设备同步**：GitHub token（只勾 gist 权限），手机电脑进度自动合并。
5. **提醒**：手机下载日历提醒；电脑运行 `reminder\提醒设置.bat`。

🔒 API Key 和 token 只保存在各自设备的浏览器里，不会同步、不会上传到别处。

## 扩充内容

内容都在 `data/` 里，按注释格式**往数组末尾追加**即可：

- `data/chunks.js` 语块　·　`data/practice.js` 听力句子 / AI 场景　·　`data/ielts.js` 雅思口语、写作题库和分数换算表　·　`data/words.js` 核心词汇

## 开发

纯静态网页，无需构建即可运行。唯一需要构建的是 Claude 接入层（官方 `@anthropic-ai/sdk` 打包成 `vendor/claude.js`）：

```bash
cd build && npm install && npm run build   # 类型检查 + 打包
npm test                                   # 端到端测试（jsdom，AI、GitHub、语音识别都用本地模拟）
```
