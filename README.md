# 🗣️ SpeakUp · 英语精进

给过了四级、但一开口就卡住的人：每天 15–20 分钟，练到能和外国队友开黑交流，最后能在外企用英语工作。

## 每天 4 项练习（全部完成 = 打卡）

| 练习 | 做什么 | 为什么 |
|---|---|---|
| 🧠 语块记忆 | 学整块的表达（267 个：FPS 游戏 / 外企职场 / 嵌入式技术 / 日常口语，另有 265 个核心词汇可选）。新语块看英文学，复习时**看中文说英文** | 流利靠的是脱口而出的整块表达，不是单词 |
| 🗣️ 说出来 | 给一个真实情境（“告诉队友 B 点两个人”），用英语说出来；AI 判断在真实场景里行不行，并给出更地道的说法 | 练的是“把想法变成英语”的速度 |
| 🎧 听说训练 | 先听写（逐词比对），再跟读（录音回放 + 识别比对） | 耳朵和嘴巴一起练 |
| 🤖 AI 陪练 | 16 个角色扮演：CS2 排位语音、安抚上头队友、外企站会、和同事排查 bug、技术面试…… 每句话都有纠错，结束后点评并一键收藏语块 | 真实对话是唯一能练出流利度的方法 |

没说好的题、忘掉的语块会自动安排之后再练；AI 点评里的好表达收藏后，第二天开始复习。

## 开始使用

1. 电脑、手机都打开同一个网址（见下方“部署”），手机上「添加到主屏幕」，像 App 一样用。
2. **我的 → AI 设置**：填一个 API Key。
   - DeepSeek：国内直连，每天练一次一个月大约几块钱。[创建 Key](https://platform.deepseek.com/api_keys)
   - Claude：质量最好，需要能访问国外网络。[创建 Key](https://console.anthropic.com/settings/keys)
3. **我的 → 多设备同步**：用 GitHub token（只勾 gist 权限）开启同步，手机电脑进度自动合并。
4. **提醒**：手机在「我的 → 每日提醒」下载日历提醒；电脑已设置 Windows 通知（`reminder\提醒设置.bat` 修改时间、联动云端进度后“练完就不提醒”）。

🔒 API Key 和 GitHub token 只保存在各自设备的浏览器里，不会同步、不会上传到别处。学习进度保存在你自己账号的私密 Gist 里。

语音识别用的是浏览器自带功能：Edge / Safari 最稳；Chrome 需要能访问 Google。不支持的浏览器可以用输入法自带的语音输入（讯飞、搜狗、微信键盘都能识别英文）。

## 扩充内容

内容都在 `data/` 里，按注释格式**往数组末尾追加**即可，已有进度不受影响：

- `data/chunks.js` 语块　·　`data/practice.js` 说出来 / 听说句子 / AI 场景 / 独白话题　·　`data/words.js` 核心词汇

## 开发

纯静态网页，无需构建即可运行。唯一需要构建的是 Claude 接入层（官方 `@anthropic-ai/sdk` 打包成 `vendor/claude.js`）：

```bash
cd build && npm install && npm run build   # 类型检查 + 打包
npm test                                   # 端到端测试（jsdom，AI 与 GitHub 接口用本地模拟）
```
